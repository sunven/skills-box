# Skills 列表多选与批量操作

Status: ready-for-agent
Implementation: complete

## 原始需求

2026-11-04：用户以「全局 Skills」列表截图为背景，要求增加多选与批量操作，并通过 grill-with-docs 逐轮确认设计、记录领域术语与必要的架构决定。

## 已确认

- 需要在 Skills 列表中选择多个条目，并对这些条目执行批量操作。
- 入口：全局、项目的已安装列表均支持；本次不扩展发现页与安装向导。
- 动作：Update（更新）、Uninstall（卸载）、Attach（挂载到 Agent）、Detach（解除 Agent 挂载）。
- 2026-11-04 追加确认：Unmanaged skill 也必须支持单项与批量卸载；无安装记录不再作为卸载拒绝原因。
- 全选：当前搜索与筛选结果中的全部条目，包括滚动区域外的行；明确显示选中数量。
- 一次 Batch operation 只作用于一个 Scope，已记录于 GLOSSARY.md。

### 多选交互（Q4、Q5）

- 表头全选框与各行复选框常驻；有选择时显示批量工具栏，包含「已选 N 项」、四种动作及清空。
- 表头选中状态按当前匹配结果计算：无选择为未选，全部选择为全选，部分选择为半选；取消表头勾选清空当前结果的选择。
- 勾选只改变选择；点击行仍打开详情。支持键盘勾选。
- 搜索或筛选改变后，仅保留仍匹配的选择；隐藏条目自动取消选择。
- 排序保留选择；刷新移除消失的条目；切换全局或项目时清空选择。
- 例如已选 10 项，筛选后仅有 3 项匹配，则后续只操作这 3 项。

### 操作资格与 Agent 目标（Q6、Q7）

- 允许混合状态选择；确认前分别列出可执行项、跳过项的数量及逐项原因。
- 无可执行项时禁用提交；Uninstall 按追加需求支持 Unmanaged，其他动作沿用原有资格。
- 批量更新仅处理受管、本地干净且有可用更新的 Skill。本地有改动或改动状态未知的 Skill 跳过，仍通过单项操作明确确认。
- 批量 Attach / Detach 为所选 Skill 统一选择一组 Agent，可多选，默认不勾选任何 Agent。
- 每个 Agent 显示能作用于多少个所选 Skill。
- Attach 仅补齐缺失挂载，已有挂载跳过；Detach 仅作用于符合现有规则的现有挂载，其他目标跳过；共享 Agent 沿用现有限制。
- Update / Uninstall 的 Batch target 是一个 Skill；Attach / Detach 的 Batch target 是一个 Skill 与一个 Agent 的组合。

### 执行、失败与停止（Q8、Q9）

- 串行执行；普通单项失败记录原因后继续处理其他目标。
- 备份失败或任务无法安全继续时终止整批，保留已经完成的操作，不自动回滚。
- 四种动作均提供「停止后续操作」：当前正在写入的单项完成后停止，尚未执行项标为未执行。
- 停止后保留已完成结果，当前写入不会被强制中断。

### 预览、确认与目标固定（Q10、Q11）

- 四种动作均先展示执行清单：Skill、Agent、可执行项、跳过项与原因。
- Uninstall 明确列出 canonical、所有 Agent 挂载、lock 与基线的删除范围，并列出 Local modification 为 modified / unknown 的目标；用户勾选删除确认后允许卸载这些目标。
- Unmanaged Uninstall 按实际路径先备份再删除，不依赖安装记录或 CLI；安装记录与基线仅在存在时清理。符号链接只删除链接本身，保留它指向的源目录；预览提示无法确认本地改动。保留项目路径边界及副本依赖检查，写入前再次核对安装记录与删除范围，批量同时核对内容。
- Detach 如涉及 copy，额外要求确认删除副本目录；普通 link 不增加副本删除确认。
- 各动作沿用各自的既有备份策略。
- 提交确认后固定本次 Skill 与 Agent，执行中锁定选择和 Scope 切换，不扩大操作范围。
- 每个目标写入前重新核对；内容或挂载范围发生变化的目标跳过，提示重新预览确认。批量更新必须重新核对本地干净状态。

### 结果、重试与选择收尾（Q12–Q14）

- 逐目标展示 success（成功）、failed（失败）、skipped（跳过）、not-executed（未执行）及原因；Attach / Detach 按 Skill × Agent 记录。
- 失败项与未执行项支持重新预览、重新确认后重试；成功项不会被重试，跳过项不自动重试。
- 成功完成的 Skill 取消勾选；失败、跳过及未执行 Skill 保留勾选。Attach / Detach 的一个 Skill 只有全部可执行 Agent 目标成功时才取消勾选。
- 对 Attach / Detach，只有至少一个可执行目标且本次全部可执行目标均成功的 Skill 才取消勾选；预览时已跳过的 Agent 不阻止其他目标成功后的取消勾选，执行期间新跳过的可执行目标视为未完成。
- 完成后的勾选仍遵守搜索 / 筛选裁剪和刷新移除消失项规则。
- 保留现有单项入口与「更新全部」。批量工具栏只作用于勾选项；「更新全部」保留现有范围。
- 执行期间禁用其他写操作，结束后恢复。

### 任务边界、顺序与预览失效（Q15、Q16）

- 一批操作作为一个后台 Mutation task，整批占用写入许可，不允许其他写操作插入；忙时明确提示稍后重试。
- 按提交确认时的列表顺序执行，Attach / Detach 先按 Skill、再按 Agent 选择器中的顺序执行；点选先后不改变执行顺序。
- 打开预览时固定所选 Skill。Agent 选择仍可在未提交的预览中调整，并随之更新清单。
- 检测到预览相关的内容、挂载、资格或项目根目录变化时，更新清单并清除已勾选的删除确认，要求重新确认。不得因列表刷新而纳入新的 Skill。
- 切换 Scope 时关闭尚未提交的预览并清空选择。执行阶段禁止 Scope 切换；每项仍须遵守 Q11 的写前校验。

### 关闭、退出与结果保留（Q17、Q18）

- 执行中弹窗保持打开，Escape、遮罩点击和关闭按钮不能将任务转为隐藏的后台任务；可通过「停止后续操作」结束。
- 批量任务运行时退出应用提供「继续等待」「停止后续并退出」。后一选项等待当前目标完成，再终止剩余目标并退出，不强制中断当前写入。
- 意外中断沿用现有中断 / 恢复提示，不自动续跑。
- 结果保留到用户主动关闭。重试先重新预览 / 确认，仅执行选定的失败与未执行目标；此前成功记录保留，重试目标的状态更新。
- 保留现有日志与备份目录入口。本次不新增历史任务页，不恢复重启前的批量结果，不自动重试。

### 计数、可访问性与窄窗口（Q19）

- 工具栏以 Skill 计数，例如「已选 3 个技能」；Update / Uninstall 的预览与进度也以 Skill 为目标单位。
- Attach / Detach 的预览以 Skill × Agent 为目标单位，分别显示可执行和跳过数量；进度按实际可执行目标计数，跳过项另列。选中 3 个 Skill 和 2 个 Agent 最多形成 6 个组合目标，不宣称有 6 个 Skill。
- 每个目标的终态都会显示；停止或整批失败后，尚未开始的可执行目标明确为未执行，预览已跳过的目标仍为跳过。
- 窄窗口允许批量工具栏换行，预览 / 结果清单在弹窗内部滚动；保留选择、技能名称、状态与操作的可用性。
- 空列表禁用全选；没有选择时隐藏批量工具栏；无可执行目标时禁用提交并提供具体原因。
- 复选框提供含 Skill 名称的可访问标签、可见焦点和半选状态，可通过 Tab 聚焦、空格切换；勾选与行操作不互相触发，不形成嵌套交互控件。

### 资格矩阵与失败归属

| 动作 | 可执行目标 | 必须跳过或拒绝的情况 | 确认与备份 |
| --- | --- | --- | --- |
| Update | 受管、有 canonical、本地干净且仍有可用更新的 Skill | Unmanaged、Copy-only、本地 modified / unknown、已最新、检查无有效结果、源路径缺失及现有资格拒绝 | 预览后确认更新；沿用既有更新备份与校验 |
| Uninstall | 满足计划规则的 Managed / Copy-only / Unmanaged Skill | 副本依赖冲突、非法目标、项目路径越界及现有计划拒绝 | 统一确认删除所有相关内容，明确列出本地 modified / unknown；先备份再卸载并校验；Unmanaged 按原始路径删除，链接仅 unlink |
| Attach | 受管且有 canonical 的 Skill，与可独立挂载、尚无目标的已检测 Agent 的组合 | 已挂载、断链或目标冲突、共享 / universal Agent、不支持该 Scope 的 Agent，以及现有 gate 拒绝 | 预览后确认；新增 link，不覆盖，不增加备份 |
| Detach | 受管且有 canonical 的 Skill，与可解除的现有 link / copy 挂载的组合 | 无挂载、Unmanaged、Copy-only、native / broken 挂载、共享 / universal Agent、副本依赖冲突及现有 gate 拒绝 | 预览后确认；link 只 unlink，copy 必须另行确认并先备份 |

- Stale lock entry 不在列表，不是 Batch target；本次不增加异常批量清理。
- 操作资格在预览和实际执行时均按上述规则核对。Uninstall 允许同一 Skill 的副本及已在其卸载范围内的引用链接一起删除；仅范围外引用属于副本依赖冲突。源路径缺失只限制 Update，不限制 Uninstall。不因另一个依赖 Skill 也被选中就豁免范围外副本依赖检查，也不自动重排来解除依赖；单 Agent Detach 仍检查所有引用。
- 已存在的全局 `~/.codex/skills` 通过「Codex（旧目录）」纳入实际挂载扫描、卸载预览和原生清理；目录不存在时隐藏。现代 Codex 的共享目录仍按 canonical 处理；旧目录不自动映射到项目。
- 普通单项目标的执行 / 校验失败记为失败并继续；目标内容或作用范围变化记为跳过，提示重新预览。
- 备份失败或影响整批继续能力的故障（如 Scope 整体失效、共享记录不可用或执行环境无法继续）停止整批；故障目标保留原因，已完成的结果保留，剩余可执行目标标为未执行。
- 预览时跳过的目标不得因执行中资格变好而自动加入本次操作；需重新预览确认。
- 操作和结果始终携带原 Scope 与目标身份，同名的全局和项目 Skill 不互相影响。

## 验收条件

1. 全局和项目的已安装列表都有常驻复选框、半选 / 全选状态、选中计数及四种批量动作；发现页与安装向导保持既有行为。
2. 只勾选一项也可使用批量入口；勾选不打开详情，行点击和现有操作按钮仍到达原有入口。
3. 搜索筛选的全部匹配项可跨滚动区域全选；已选 10 项筛选后剩 3 项时，只保留 3 项。排序不清选择，Scope 切换清空。
4. 混合 Managed、Unmanaged、Copy-only、本地 modified / unknown、已最新与可更新项时，每种动作的预览和实际执行均符合资格矩阵，跳过项可见具体原因。
5. Agent 默认未选；3 个 Skill × 2 个 Agent 的预览区分可执行和跳过目标。已有挂载不覆盖，无挂载不误删，共享 Agent 不独立操作，副本依赖冲突不被批量选择绕过。
6. 卸载无法绕过删除确认；copy Detach 无法绕过副本删除确认。预览相关状态变化后确认失效；更新发现新的本地改动时不覆盖。
7. 同名 Skill 在全局和两个项目中选择、执行、刷新与结果完全隔离；执行中无法改变 Scope 或目标，其他写操作及 Relocate / Forget 无法插入。
8. 按确认顺序串行执行。第 2 个目标普通失败时，第 3 个仍执行；第 2 个备份失败时，第 1 个结果保留，第 3 个显示未执行，没有自动回滚。
9. 在第 2 个目标写入中点击停止，第 2 个完成，第 3 个不开始；重复停止或提交不导致重复执行。退出时选择停止后续并退出同样等待当前目标完成。
10. 执行前内容、挂载或来源发生变化不会扩大已确认的操作；预览已跳过的目标不因新资格自动执行。
11. 结果逐目标显示四种终态、原因与现有备份 / 日志入口；重试只处理重新确认的失败 / 未执行目标，既有成功记录保留，跳过项不自动重试。
12. 成功 Skill 自动取消勾选，失败 / 跳过 / 未执行 Skill 保留；多 Agent 部分失败的 Skill 保留勾选，全部可执行 Agent 成功的 Skill 取消勾选；刷新已消失项不残留。
13. 空列表、无可执行项、窄窗口、长名称、长结果清单、键盘 Tab / 空格、焦点与半选状态可正常使用；单项入口和更新全部继续保持原有业务范围。
14. 意外中断不自动续跑；关闭结果与重新启动不要求恢复批量结果页面，现有日志、备份和中断提示仍可用。

## 环境事实

- 全局与项目共用 `src/components/skill-list-pane.tsx`；现有单行选中用于打开详情，没有批量勾选。
- `updateSkills(names, ...)` 已接收多个名称；现有更新全部仅包含受管、本地干净且有更新的条目（`src/lib/update-view.ts:338`）。本地已改动或状态未知的更新需要单项确认。
- 初始调研时 Uninstall 接口及计划只接收一个 Skill，支持 Managed / Copy-only、拒绝 Unmanaged。2026-11-04 用户追加要求后，已扩展为支持 Unmanaged；副本依赖仍须检查。
- 当前 Uninstall 不按 Local modification 状态阻止删除；单项弹窗统一要求确认删除 canonical、所有挂载、lock 与基线，并说明备份和不自动回滚（`src/components/uninstall-dialog.tsx:199`、`src-tauri/src/tasks/uninstall.rs:80`）。批量沿用资格并加强预览的本地改动提示与删除确认，见 Q10。
- Attach 弹窗支持一个 Skill × 多个 Agent，逐 Agent 执行；Detach 目前是一个 Skill × 一个 Agent。
- Attach / Detach 要求受管 Skill 与 canonical 目录；共享或 universal Agent 不能独立挂载或解除挂载。Detach 仅支持符合现有规则的 link / copy。已有挂载不能被 Attach 覆盖（`src-tauri/src/attachment_target.rs`）。
- Stale lock entry 仅出现在异常汇总，不是可选列表行；异常清理仍为原有单项入口，本次未纳入。
- 写操作共享单写入许可，Project Relocate / Forget 也使用此许可（ADR-0013、ADR-0016）。不能直接并发调用现有写接口来实现一批操作。
- 现有更新逐 Skill 串行执行，在 Skill 之间允许取消；单项写入期间不允许取消。普通执行或校验失败可继续下一项，备份 preflight 失败会终止任务；备份不等于自动回滚。
- 各动作备份策略不同：Attach 只新增符号链接，不创建备份；Detach 的 link 只 unlink，copy 先备份再删除；Update / Uninstall 采用各自的既有快照策略（`src-tauri/src/attach.rs:67`、`src-tauri/src/detach.rs:136`）。不能把「执行前备份」笼统描述为四种动作的共同步骤。
- 现有 Update 开始时一次性生成计划，逐项 preflight 不重新检查本地干净状态；后端也不复核前端候选资格（`src-tauri/src/tasks/update.rs:91`、`:190`、`:400`）。Q11 所要求的即时校验是本次必须补齐的行为。
- 当前 session 的备份失败直接返回整体错误，可能丢失已累计的结果行（`src-tauri/src/tasks/session.rs:294`）。本次停止整批时必须保留全部已完成结果及未执行目标。
- 现有结果没有独立的未执行状态；只有 Update 有失败项重试。Q12 要扩展结果与重试协议（`src/lib/mutation.ts:65`、`src/components/mutation/mutation-result.tsx:46`）。
- Native Attach / Detach 未注册为 task；旧关窗提示只覆盖已注册 Mutation task。当前确认退出应用会立即终止 CLI，区别于本次停止后续、等待当前目标完成的语义（`src-tauri/src/lib.rs:171`、`src-tauri/src/tasks/manager.rs:536`）。
- 日志已持久化到 `logs/operations.jsonl`，UI 只有打开日志 / 备份目录，没有历史任务页或重启恢复批量结果。日志写入为 best effort（`src-tauri/src/logs.rs:72`、`:94`）。
