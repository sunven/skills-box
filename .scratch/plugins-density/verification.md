# 插件页密度调整

日期：2026-11-24

用户要求：用 unslop 优化插件页面，不要太多空白

## 审视与方向

沿用先前确认的轻度打磨方向，保留现有中性色、Geist 字体、市场导航与插件列表

- 产品：为 Codex 与 Claude Code 用户管理原生插件与市场
- 气质：克制、精确、可信
- 场景：开发工具中的插件目录
- 重点：插件名称、安装状态与操作
- 辨识细节：等宽的 `插件名@市场` 坐标与版本

发现：顶部标题与工具区间距偏大；市场栏与列表之间占用较多横向空间；名称与坐标单独成行；插件行上下间距和信息间距叠加；市场详情和空结果留白偏多

## 各层处理

| 层次 | 处理 |
| --- | --- |
| 间距 | 页面边距改为 20 / 24px，插件行上下各 12px，描述与状态间距各 4px；市场详情分隔间距由 20px 改为 12px |
| 色彩 | 沿用现有中性色阶、蓝色选择标记与有语义的状态色 |
| 图标 | 保留项目已有 Lucide 16px、1.5 描边 |
| 文案 | 保留插件内容、范围说明和操作文案 |
| 字体 | 页面标题 20px / 28px、500 字重；坐标行高 16px，名称、描述和状态字号保持可读 |
| 布局 | 名称与坐标在宽窗口并排，空间不足时自然换行；市场栏从 224px 改为 200px，列表左内边距从 24px 改为 16px |
| 细节 | 完整保留坐标、版本、安装来源、设置与生效状态；保留按钮焦点与弹窗操作 |
| 视觉 | 用真实插件内容提供重点，没有添加图片或装饰，无图片提示词 |
| 动效 | 沿用已有控件反馈与减少动效支持 |

## 验证

- 1280 × 800：两条预览插件行均由 153px 降至 97px，减少约 37%；搜索栏由 y=249px 上移至 y=217px
- 820 × 720：市场详情与操作按钮正常排列，插件操作换行，无横向溢出
- 390 × 844、320 × 640：插件页无横向溢出，窄窗口名称和坐标可换行
- 市场选择、搜索、安装状态组合筛选与空结果提示正常
- Claude Code 宿主切换、插件详情、启用确认正常；弹窗打开后焦点在内部，Escape 可关闭
- Tab 从搜索移至安装状态筛选，显示 2px 焦点轮廓
- axe WCAG A/AA 插件列表：0 violations / 0 incomplete；启用确认：0 violations / 1 incomplete，自动工具要求人工检查原有 li / pre 的对比度，本次未修改这些元素的样式
- `pnpm exec vitest run src/components/native-plugins-page.test.tsx src/App.native-plugins.test.tsx`：13 项通过
- `pnpm build`：通过，仍有已有的主 bundle 超过 500 kB 提示
- `git diff --check`：通过

浏览器检查使用 `preview.html` 的 Fake backend，未验证真实宿主命令执行；此次修改未涉及原生协议或状态逻辑
