1. **范围**：本次仅改技能市场详情。Global scope 与 Project 中已安装技能的右侧详情抽屉另行讨论。
2. **页面形态**：市场列表进入占满主内容区的独立详情视图，左上角可返回列表。返回时保留搜索条件和列表位置。
3. **视觉方向**：采用参考图的信息层级与留白比例，沿用 Skills Box 的字体、颜色和按钮风格。第一版按「名称与来源 → 简介与标签 → 分隔线 → 大面积正文」排列；只有概述时省去单选项标签栏。
4. **功能范围**：第一版聚焦概述和安装入口，使用已有真实数据。评论、评分、安全报告与版本历史不在本次范围内。

用户于第二轮回复「按推荐」，确认 Q5–Q7：

5. **安装流程**：详情页右上角提供「安装」，点击后打开独立弹窗，选择 Agent、预览并确认安装。沿用现有版本核实、执行进度与结果反馈；关闭安装弹窗后仍停留在当前市场详情。
6. **概述阅读**：默认完整渲染平台提供的 `SKILL.md`，提供次要的「查看原文」入口。正文前用分隔线划分区域，不显示只有「概述」一个选项的标签栏。远程文件浏览不在本次范围内；未来增加内容分区时再显示标签栏。
7. **已安装条目**：当前 Scope 已安装同一市场技能时，仍可阅读市场详情，主要操作改为「查看已安装技能」。市场详情展示平台发布信息；该操作进入现有本地管理抽屉，查看本地内容、Agent attachment 与更新状态。

用户于第三轮回复「按推荐」，确认 Q8–Q10：

8. **切换 Scope**：在市场详情页切换 Global scope 与 Project 时，保留当前市场条目和阅读位置，只刷新当前 Scope 的已安装状态与安装目标。安装弹窗打开后固定目标 Scope；更换目标需关闭弹窗后重新选择。弹窗预览、版本核实与执行期间，沿用已有的关闭限制和取消规则。
9. **长文操作入口**：精简操作栏吸顶，保留「返回列表」、技能名与「安装／查看已安装技能」。简介及较大的标题区域正常随正文滚动。
10. **标题信息**：展示技能名称、发布者、完整市场坐标、平台版本、简介、收藏数、下载量、已声明的 API Key 运行要求和官方页面入口。使用名称首字作为图标占位；第一版不新增真实图标、分类标签或更新时间的数据接入。缺失的可选元信息省略；收藏数与下载量沿用列表规则，缺失显示「—」，真实零显示 `0`，大数按「万／亿」紧凑显示并可查看完整数值。

## 页面与状态规则

- **布局**：保留应用导航，主内容区显示独立市场详情。适配窗口宽度，保持正文易读；长坐标、代码块和表格不得挤出页面操作。
- **信息顺序**：返回与主要操作 → 名称及发布信息 → 简介、真实统计和运行要求 → 分隔线 → SKILL.md 正文。第一版没有横向标签栏。
- **正文**：渲染与原文显示同一平台版本的 SKILL.md。继续遵循现有 Markdown 的 frontmatter、HTML、远程图片及链接处理规则，不增加远程文件树或编辑能力。
- **安装**：点击主要操作后进入独立安装弹窗，展示明确的目标 Scope。弹窗不重复承担长篇概述阅读；保留现有 Agent 选择、预览、确认版本固定、真实命令、进度、依赖提示、失败和结果反馈。
- **安装成功**：保留结果供用户查看；关闭弹窗回到原详情及阅读位置，当前 Scope 的安装状态刷新。结果中的「查看已安装技能」仍进入现有本地管理入口，不自动跳转。
- **本地管理跳转**：「查看已安装技能」沿用现有导航到当前 Scope 的技能清单并打开管理抽屉。市场卡片已有的「已安装 · 查看」快捷入口保留；点击卡片标题仍进入市场详情。
- **返回列表**：恢复已提交搜索、输入框内容、排序、分类、API Key 筛选、页码和列表滚动位置。
- **加载与失败**：沿用原市场规格的加载、重试及保留成功结果规则；旧内容需明确标记，另一条目的内容不能冒充当前条目。安装前继续核实完整身份与目标版本。
- **Scope 状态**：公共市场内容独立于 Scope；安装状态、名称冲突、Agent 资格与写入可用性属于当前 Scope。新 Scope 的清单尚未就绪时，不得沿用旧 Scope 的安装状态或允许错误目标的安装。

## 已核实的当前能力

- 市场详情当前在同一弹窗内展示远程信息、SKILL.md、Agent 选择、安装确认、进度与结果。
- 已有名称、描述、发布者、完整市场坐标、平台版本、官方页面、SKILL.md 与已声明运行要求。市场摘要有收藏数和下载量；收藏数不代表评分。
- 已安装技能的内容浏览器读取本地文件；市场详情目前没有远程文件树或单独的 README 数据。
- 市场浏览与详情无需 SkillHub CLI；安装依赖 CLI。

## 已确认行为的验收场景

1. 从市场列表进入详情，主内容区呈现完整阅读页面；返回后搜索、排序、分类、API Key 筛选、页码及列表位置保持。
2. 正文默认完整渲染 SKILL.md，可查看原文；没有评论、评分、安全报告、版本历史、远程文件树或单选项标签栏。
3. 点击右上角「安装」后才进入 Agent 选择、预览、确认、进度及结果流程；关闭弹窗回到同一市场详情。
4. 当前 Scope 已安装同一市场条目时，详情仍展示平台发布信息，操作显示「查看已安装技能」并进入现有本地管理入口。
5. 缺少 SkillHub CLI 时仍可阅读详情，安装入口沿用现有依赖提示及重新检测行为。
6. 本次页面改动继续遵循原市场规格中的身份、同名冲突、确认版本固定、失败反馈与安装结果核验规则。
7. 阅读长文时精简操作栏吸顶，返回和主要操作始终可达；窄窗口中主要操作、长坐标、代码和表格保持可用。
8. 切换 Scope 后保留当前条目与阅读位置，已安装状态、同名冲突和 Agent 目标取自新 Scope；清单加载中不复用旧 Scope 的安装资格。
9. 安装弹窗打开时目标 Scope 固定，关闭后可切换；预览及执行期间的关闭、取消规则符合现有 Mutation surface。
10. 安装成功关闭结果后，详情位置保持且操作变为「查看已安装技能」；用户主动点击查看才进入本地管理。
11. 标题区展示平台版本、完整身份、真实统计和已声明运行要求；缺失字段与真实零有区别，收藏数不被表示为评分，未接入数据不生成虚构值。
