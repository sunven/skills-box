# 03: 异常处理界面与结果刷新

Status: resolved
Blocked by: 01, 02
Parent: [spec.md](../spec.md)

## What to build

异常弹窗的失效记录卡片增加「处理」入口，打开当前 Scope 的完整记录清单，展示名称、Source、资格和原因，支持单项选择与全选，默认未选。提供独立的「清理记录」与「恢复技能」动作。

复用现有 Mutation surface：整批预览确认、固定目标、进度、停止后续操作、逐项结果、打开备份和重新预览重试。恢复支持 ref 展示与 Agent 多选，默认 canonical。最终按钮以可执行数量显示「清理 N 条记录」或「恢复 N 个技能」。

更新过时的 v1/只读文案；清理资格不受缺少 Node/Git 的恢复能力限制。切换 Scope 清空旧选择，写入中限制目标和 Scope 切换。结束后同步库存、异常计数、完整记录清单及发现关联，只更新受影响的 Skill 检查结果。

扩展共享 Fake backend 的清单、计划、记录清理和恢复语义，供真实交互集成测试和浏览器预览使用。

## Validation

App 集成测试覆盖 21 条完整清单、默认未选、全选、预览数量、两种独立动作、Agent 默认值、工具缺失、作用域切换、进度/失败/重试/备份和结果刷新。浏览器验证桌面与窄窗口下的可读性、键盘操作和 modal 焦点。
