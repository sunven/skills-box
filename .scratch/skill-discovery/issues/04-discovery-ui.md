- 扩展 types/API/Fake backend，组件仍通过统一 IPC gateway 调用。
- 顶部入口与全应用未读数量；默认当前 Scope 未安装，提供全部/新增/已忽略、搜索和来源筛选。查看全部新增能访问数字包含的所有项。
- 显示来源扫描进度、尝试/成功时间和保留结果的错误状态；提供手动扫描，不自动弹出安装/更新框。
- 单项详情、全部已读、忽略/恢复；异步失败不伪装保存成功，卸载仅改变安装投影。
- Scope 安装状态与来源身份区分：其他 Scope 已装不隐藏当前未装；不同源同名、Unmanaged、Stale lock 和不可读 Scope 明确呈现冲突/未知。
- 发现项安装向导预填 Source 与单项意图，实际预览后只预选点击项；Scope 切换可重新预览，缺失/歧义项不直接启动安装。
- 安装结果只对实际成功项标已处理；数据刷新使新来源立即被发现、最后来源消失后停扫。
- 自动调度覆盖应用级来源，保持 run 跨页面/Scope 存活；StrictMode、手动/自动并发及六小时计时不能重复启动。
- 页面返回沿用当前主列表及 Scope 切换行为；普通手动安装与设置页流程通过回归。
