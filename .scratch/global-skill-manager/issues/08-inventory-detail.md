# 清单与详情的信息规则

Type: grilling
Status: resolved
Blocked by: 02, 05

已知事实（来自「更新检测机制与成本」）：更新徽章的数据来自 GUI 自建检查器，需区分 up-to-date / update-available / unknown / path-missing / error。

已知事实（来自「全局安装的真相与异常形态」）：`list --json.agents` 会高报挂载（本机 41 vs 实际 10）；lock 不含安装模式。列表的 agent 覆盖、链接 / 副本状态必须从各 agent 物理目录推断，并区分受管 / 未受管 / stale / ghost 条目。

已知事实（来自「CLI 能力与 JSON 契约」）：`list -g --json` 缺 description、时间、hash 和挂载模式；详情需组合 lock、`lstat` 与 `SKILL.md`，不能只靠 list。

已知事实（来自「安装向导的来源预览与选择契约」）：安装预览只显示 name+description；path 与完整元数据在安装后的详情中展示。

## Question

在安装状态模型与界面原型的基础上，确定列表和详情展示什么、如何组织：

- 列表：按来源包分组还是平铺；排序（名称 / 更新时间 / 来源）；搜索匹配哪些字段；筛选维度（来源、agent、更新状态、异常）；同名 skill 多来源如何区分。
- 行内信息：名称、描述、来源、agent 覆盖（图标 / 计数）、更新徽章、异常徽章、最后更新时间；信息密度与截断规则。
- 详情：元数据、挂载的 agent 及链接 / 副本状态、来源与 commit、lock 时间、目录路径、只读 `SKILL.md`（渲染 / 原始切换）、打开 Finder / 外部编辑器。
- 空 / 加载 / 错误状态：无 skill、CLI 缺失、网络失败、锁与目录不一致的只读横幅；刷新与手动重新扫描。
- 动作入口：安装、检查更新、更新、断开、卸载分别放在哪里，避免误触。

输出：列表字段表 + 详情分区 + 状态徽章定义 + 动作位置，写入 `## Answer`。只闭合本票据。

## Answer

用户确认（2026-10-28）。

### 领域规则

- 名称是 skill 的身份；一行一个 name。来源来自 lock；不因多来源产生重复行；同名冲突在安装向导中禁用，换源需先卸载。
- 状态正交，不合并为单一字段：
  - **更新状态**：已是最新 / 可更新 / 未知 / 检查失败 / 源路径缺失。
  - **管理状态**：受管 / 未受管 / 仅副本（有 lock 无 canonical）。
  - **警告**：本地改动（是 / 否 / 未知）、未挂载、断链（agent 级）。
- 时间：受管 skill 用 lock.updatedAt；未受管显示「—」，详情另示目录 mtime。更新时间检查时间显示在检查按钮的 tooltip 或页头，不占行内。
- 描述来自 `SKILL.md` frontmatter；缺失显示「—」并在详情提示；读取失败显示行内警告，不崩溃。

### 列表

- 平铺列表，不按来源分组；来源作为侧栏筛选与排序维度。
- 默认按 lock.updatedAt 倒序；可切换名称、来源；同名用 name 做稳定 tie-breaker。
- 搜索匹配 name / description / source；不搜 `SKILL.md` 正文与 path；即时过滤，无需防抖。
- 筛选：来源、agent、状态；状态筛选项为 全部 / 可更新 / 已是最新 / 未知 / 异常 / 未受管。
- 「异常」包含 path-missing、检查失败、本地改动、断链、仅副本；未挂载只提示，不计异常；未受管独立筛选。
- 结果计数显示当前过滤结果数；来源 / agent / 状态计数基于完整库存，不随其他筛选收缩；选中项被过滤掉时自动选中首条。
- 行内字段：

| 字段 | 来源 | 规则 |
|---|---|---|
| 名称 | 目录 / SKILL.md | 主标识 |
| 描述 | SKILL.md frontmatter | 单行截断；缺失显示「—」 |
| 来源 | lock | 未受管显示「—」 |
| Agent 覆盖 | 物理挂载 `lstat` | 头像堆叠，最多 5 个 + n；不使用 `list -g --json.agents` |
| 更新状态 | GUI checker + lock hash | 见徽章定义 |
| 管理状态 | lock / canonical | 未受管、仅副本 |
| 警告 | baseline / 挂载 | 本地改动、未挂载、断链 |
| 更新时间 | lock.updatedAt | 未受管显示「—」 |

- v1 不做虚拟列表 / 分页；目标规模 50–100 条，直接渲染滚动。

### 状态徽章

| 维度 | 值 | 色调 | 说明 |
|---|---|---|---|
| 更新 | 已是最新 | 绿 | 远端 tree hash 与基线一致 |
| 更新 | 可更新 | 琥珀 | 远端 hash 不同 |
| 更新 | 未知 | 灰 | 无 hash / 无法比较 / 缓存缺失 |
| 更新 | 检查失败 | 红 | 网络、限流、仓库不可达；保留上次结果，不误报最新 |
| 更新 | 源路径缺失 | 红 | 上游仓库存在但记录的 skillPath 不存在 |
| 管理 | 未受管 | 橙 | 有目录无 lock；只读 |
| 管理 | 仅副本 | 橙 | 有 lock 无 canonical；可卸载，不可更新 / 断开 |
| 警告 | 本地改动 | 琥珀 | 基线或 lock hash 判定有改动 |
| 警告 | 本地改动? | 灰 | 无基线且 lock hash 不一致，无法判断 |
| 警告 | 未挂载 | 灰 | 无任何 agent attachment；不计异常 |
| 警告 | 断链 | 红 | agent 挂载级；不修复 |

### 详情

- 头部：名称、更新/管理/警告徽章、描述、动作。
- 概览：来源、ref、skillPath、安装时间、更新时间、canonical 路径（仅副本显示 agent 路径）、hash（短显示、可查看完整）、本地改动状态、更新状态、管理状态。
- Agent 挂载：每个 agent 的名称、目录、模式（链接 / 副本 / 共享 / native / 未受管 / 断链）与断开入口；universal/native 不给断开；无挂载显示「未挂载」。
- `SKILL.md`：默认渲染，提供原文切换；渲染视图隐藏 frontmatter，不加载远程图片、不渲染原始 HTML；链接通过 opener 打开；原文视图显示完整文件；内容按需读取，缺失 / 损坏显示警告。
- 动作：检查更新、更新（仅可更新）、彻底卸载（仅受管）、Finder / 默认编辑器；不内置编辑。未受管仅保留 Finder；仅副本仅保留卸载 / Finder；path-missing / error 可检查与卸载，更新禁用；无挂载时更新仍可用（`-a universal`）。
- 警告：本地改动、cross-link、未受管、仅副本、path-missing/error、断链分别展示，文案与危险动作一致。

### 动作位置

- 全局：安装、检查更新、刷新、环境状态，位于页头。
- 单 skill：检查、更新、卸载、Finder/编辑器，位于详情。
- 单 agent：断开，位于 agent 行。
- 列表行不放破坏性动作；点击行只切换详情。

### 异常、刷新与错误状态

- 未受管进主列表只读；仅副本进主列表但受限；stale lock / ghost 不进主列表，只在「异常 N」弹窗；断链在 agent 行只读；不做修复。
- lock 损坏或 `version != 3`：全屏错误，禁用所有变更，显示 lock 路径与「打开目录」；不伪装成空列表，不静默当空 lock。
- CLI 缺失：环境横幅，禁用变更；清单若仍可读则只读展示，否则错误面板。
- 网络失败：保留上次更新徽章并标「检查失败」，不显示「已是最新」；详情展示上次成功检查时间。
- 加载：列表/详情骨架或局部 spinner，不阻塞整窗。
- 刷新：手动刷新 + 变更后自动刷新；不做文件监听 / 后台轮询；外部 CLI 改动需手动刷新。
- 空库存、无搜索结果、无选中分别有空态；单个 skill 读取失败只影响该行/详情，不拖垮列表。
- 异常弹窗按类别列数量与示例：stale lock、未受管、断链、本地改动、源路径缺失；横幅总数包含不在列表中的 stale ghost。
