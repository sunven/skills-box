# 原生插件项目支持：实现与验收

日期：2026-11-20。按用户已确认的 Q1–Q9 实现；代码和验收已完成，未发布安装包。

## 已实现

- 插件与技能共用项目列表、活动作用域及添加、重新定位、遗忘入口。插件页显示项目名称、根目录和宿主配置层，不再显示技能更新徽章或技能锁错误。
- Claude Code 默认使用项目共享层，也可切换「仅自己在此项目」。安装、启停、更新、卸载和市场声明写入调用官方 CLI，明确传入 `--scope project` / `--scope local` 和注册表解析的 cwd。
- 区分当前层安装、其他层安装、当前层启用设置、覆盖来源及宿主报告。项目可以覆盖继承的全局安装；只有配置、市场目录缺失及安装待核对的条目不会消失。
- 市场声明来源与共享缓存分开显示。同步、更新列出原生安装身份、作用域和项目路径；已知市场配置也进入影响列表。安装记录中未注册或已遗忘的项目仍参与保护。
- 卸载和移除市场在存在其他层安装时阻止；声明来自其他层、原生清单不完整、目录或影响不明确时说明原因。前端按钮与后端预检使用同一操作约束。
- Codex 通过带 cwd 的官方 `config/read` 读取项目层、来源和覆盖。项目写入保持禁用，分别解释官方用户配置写入限制与尚未验证的其他项目操作；不自动写全局。
- 确认包含作用域身份、项目根、配置层、CLI 和配置指纹。执行取得既有公共写入许可后重新解析项目；重新定位、遗忘、外部配置变化使旧确认失效。旧读取、详情或预览不能覆盖新的页面上下文。
- 写后比较其他层配置和安装身份；共享更新允许所列对象的内容版本变化，但不允许跨层删除安装或更改启用设置。沿用退出等待、异常结果保留及不自动重试的生命周期。
- 查询键包含宿主、项目、层、根目录与 revision；变更后使所有插件列表和详情缓存失效。操作结果保留原操作的项目名称和层级。

主要代码：`src-tauri/src/native_plugins/context.rs`、`model.rs`、`mod.rs`、`operations.rs`，以及 `src/components/native-plugins-page.tsx` 和共享 ScopeSwitcher。

原生结果和检查摘要保存在 [verification/](verification/)。浏览器使用 `agent-browser` 的独立 worktree 会话，检查结束后关闭浏览器与本地开发服务。

## 保留的能力边界

- Codex 当前项目写操作未开放；配置写入被官方接口拒绝，安装、重装、卸载和同步的项目副作用未单独证明可满足本规格。按钮禁用不计作这些操作验收成功。
- 两宿主均不提供独立「恢复继承」按钮，不以显式启用、重装或直接编辑配置冒充清除覆盖。
- 跨层删除没有强制执行选项。市场仅有声明但缺少可核对的缓存时，可查看声明，相关操作交由宿主处理。
- 原生加载结果无法确认时显示未知。配置来源不是已运行会话的加载证明；组织策略、信任和认证仍由宿主决定。
- 项目重新定位不迁移宿主旧路径记录。显示不可用原生路径提示，并保留详情中的旧路径；需要在宿主修复或重新安装。
- 基本兼容性检查只覆盖用户层，不解除项目层失败缓存或 Codex 项目限制；界面和错误消息明确说明此范围。
- 沿用既有安装来源限制；不新增组件执行、自动批准、批量操作或完整插件备份。浏览器验收使用 Fake backend，原生写入验收由后端隔离测试完成。

## 复现

```sh
pnpm test
pnpm build
cargo test --manifest-path src-tauri/Cargo.toml --lib
cargo test --manifest-path src-tauri/Cargo.toml native_plugins --lib
cargo test --manifest-path src-tauri/Cargo.toml native_project_layers_isolated_lifecycle --lib -- --ignored --nocapture
cargo test --manifest-path src-tauri/Cargo.toml native_codex_project_context_is_readable_without_global_write_fallback --lib -- --ignored --nocapture
cargo test --manifest-path src-tauri/Cargo.toml native_adapters --lib -- --ignored --nocapture
```

真实 CLI 测试使用源文件中明确指定的本机 executable；在其他机器运行需调整该测试路径。它们默认忽略，普通单元测试不会调用真实宿主写入。
