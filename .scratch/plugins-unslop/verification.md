# 插件页面打磨

日期：2026-11-20。状态：已实现并验证。

## 方向与范围

用户确认采用轻度打磨：延续灰白配色、Geist 字体、市场导航与插件列表的双栏结构。

- 产品：为使用 Codex 与 Claude Code 的开发者管理原生插件与市场。
- 性格：克制、精确、可信。
- 世界：开发工具里的插件目录。
- 重点：插件名称、安装状态与用户设置的阅读层级。
- 辨识细节：等宽的 `插件名@市场` 坐标与版本。

代码位于 `src/components/native-plugins-page.tsx` 与 `src/index.css` 的 Native Plugins 样式段。原生操作协议和状态归属遵循 ADR-0037、0038、0039。

## 审视结果与九轮处理

| 层次 | 发现与处理 |
| --- | --- |
| 间距 | 页面与控件混用 5、9、15、26px 等间距；页面、市场列表、插件行与弹窗统一为 4px 节奏，紧凑控件沿用应用组件尺度 |
| 色彩 | 保留现有中性色阶；市场选中采用现有 active 底色、细边框和 2px 蓝色标记，悬停采用 raised 底色；绿色仅表示用户设置为启用 |
| 图标 | 插件页 Lucide 图标统一为 16px、1.5 描边，继承文字颜色；搜索图标与输入框合为一个控件 |
| 文案 | 明确 Codex / Claude Code 的管理对象；简化生命周期、契约验收与 Sparse 等实现术语；搜索与筛选空结果引导调整条件 |
| 字体 | 来源、版本、状态由 10px 提高到 12px；描述 13px、名称 15px；坐标与版本使用等宽字体和等宽数字 |
| 布局 | 保留章节顺序与双栏结构；搜索和筛选均为 36px；820px 下操作自然换行，640px 以下改为单栏 |
| 细节 | 市场选中增加 aria-pressed；版本增加屏幕阅读器文字；安装与启停操作获得清晰按钮边界；弹窗表单可滚动，底部操作保持可见 |
| 视觉 | 由真实插件信息承担视觉重点；本次没有生成图片，也没有图片提示词 |
| 动效 | 悬停仅变化颜色与背景，统一 150ms 缓动；保留读取中的旋转反馈，尊重减少动效设置 |

## 验证

- `pnpm exec vitest run src/App.native-plugins.test.tsx`：5 项通过。
- `pnpm build`：通过；保留已有的主 bundle 超过 500 kB 提示。
- `git diff --check`：通过。
- 浏览器使用 `preview.html` 的 Fake backend；验证市场选择、搜索与状态组合筛选、空结果文案、宿主切换、启用确认与结果、本地详情、添加 Git 市场表单及确认前取消。
- 1280×800、820×720 复看截图；390×844、390×568 测量页面与表单，没有横向溢出。短窗口表单内容可滚动，底部操作位于内容区之后并处于窗口内。
- 键盘 Tab 从搜索移至筛选时显示 2px 焦点轮廓；弹窗打开后焦点位于弹窗内，Escape 可关闭。
- axe WCAG A/AA：列表、插件确认、插件详情均为 0 violations / 0 incomplete。
- 添加市场表单为 0 violations / 1 incomplete：自动工具无法判断提示段落的背景。人工核对元素边界无重叠、背景为白色，文字 `#5c636b` 对比度 6.08:1。列表元数据对比度 5.52:1，启用状态对比度 4.74:1。
- 浏览器页面错误为空。界面检查仅使用 Fake backend。
